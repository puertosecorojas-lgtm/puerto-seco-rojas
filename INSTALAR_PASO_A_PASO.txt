SI ALGO NO FUNCIONA — errores comunes
──────────────────────────────────────────────────────────────

"Sin Supabase" (rojo)
→ Hacé clic en "Sin Supabase" y te lleva a Configuración → Keys
→ Ingresá la URL de Supabase ahí (Settings → API en Supabase)

"Error al generar email"
→ La Groq key puede haber vencido. Andá a console.groq.com,
  iniciá sesión, creá una nueva key y actualizala en:
  Vercel → Settings → Environment Variables → GROQ_API_KEY → Edit → Redeploy
  O más fácil: Configuración → Keys dentro del CRM → ingresá la nueva key → Guardar

"Error Gmail: contraseña incorrecta"
→ La contraseña de app de Gmail puede haber expirado
→ Andá a: myaccount.google.com/apppasswords
→ Creá una nueva (nombre: "Puerto Seco CRM")
→ Actualizá GMAIL_PASS en Vercel → Redeploy

"No carga nada / pantalla en blanco"
→ Limpiar caché: Ctrl+Shift+R en el navegador
→ Probar en modo incógnito (Ctrl+Shift+N)
